# Product roadmap

## V1 — included now
- Local tasks and reminders
- Planner
- Notes
- Habits / streaks
- Offline assistant commands
- Optional AI chat through secure backend
- Themes and onboarding

## V1.5 — polish after phone testing
- Custom date/time picker
- Recurring reminders
- Better natural-language action parser
- Home-screen widget
- Notification actions (Done / Snooze)
- Export / backup
- App icon and brand lockup finalization
- Haptics and micro-animations

## V2 — connected assistant
- Google Calendar integration
- Gmail reading/drafting only with explicit user actions and permissions
- Morning / evening brief
- Voice input
- AI-generated day plan that can propose actions for confirmation
- Search across notes/tasks

## V3 — optional sync
- User account and encrypted cloud sync
- Multi-device continuity
- Family/shared lists with privacy controls
- Subscription tier only if it provides real value
