LIFEMATE AI — PREMIUM V3 START HERE
===================================

GITHUB / APK
------------
1) Extract this ZIP.
2) Upload everything INSIDE this folder to the ROOT of your existing GitHub repository, replacing the old V2 files.
3) GitHub > Actions > Build Android APK and AAB > Run workflow.
4) When it turns green, download Artifacts > LifeMateAI-debug-APK.
5) Extract and install the APK on Android.

WHAT IS FIXED IN V3
-------------------
- Home quick buttons now perform the expected action.
- New Task opens the task form directly.
- Quick Note opens the note form directly.
- Dashboard metric cards open their matching sections.
- AI screen has connection status, retry, clear-chat and better prompt buttons.
- Settings has Test AI Connection.

REAL AI
-------
A secure OpenAI backend is INCLUDED in backend/cloudflare-worker/.
Do NOT put an OpenAI API key inside the Android app.

Read AI_SETUP_EASY.md when you are ready to switch on real AI.
Until then the offline assistant still supports task/reminder commands.

PLAY STORE
----------
The normal release AAB from the basic build may be unsigned. Use the signed-release workflow only after your Play Store signing key has been configured safely.
