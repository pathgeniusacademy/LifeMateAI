# Privacy Policy — LifeMate AI (Draft for V1)

**Last updated: 5 September 2026**

LifeMate AI is designed as a local-first personal organization app.

## Data stored on the device
Tasks, notes, habits, streaks, app settings and recent assistant chat history are stored locally on the user's Android device in V1.

## Internet use
The core organizer works without internet. If the user chooses to configure the optional AI backend, chat content submitted to the assistant is sent to that backend so a response can be generated.

## API keys
OpenAI API keys are not stored in the Android application. The optional backend is designed to keep provider credentials on the server.

## Notifications
The app may request notification permission to show task reminders created by the user.

## Accounts and advertising
V1 does not require an account and does not include advertising or third-party advertising trackers.
