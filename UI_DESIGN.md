# LifeMate AI V2 — UI Direction

## Goal
Premium enough to feel like a paid productivity app, but simple enough that a new user understands the home screen in seconds.

## Design rules
- One dominant action: Ask LifeMate.
- Calm background with high-contrast white surfaces.
- Large rounded cards and large tap targets.
- Home answers three questions: What matters now? What can I do quickly? How am I doing today?
- AI is visible but never blocks offline features.
- No dense dashboards, tiny text, or unnecessary charts.
- Dark mode uses the same information hierarchy.

## Core visual structure
1. Personal greeting + settings
2. Premium day-summary hero
3. At-a-glance metrics
4. Four quick-action cards
5. Today's tasks
6. Habit progress
7. Five-item bottom navigation
